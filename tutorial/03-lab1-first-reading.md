# 實作 1:接上 IMU,讀出第一筆資料

目標:把 CMP10A 接上電腦,用校正工具的「即時資料檢視」看到原始數值,
並確認靜置時的讀數符合單元 1 的物理預期。**本實作不寫入任何設定**。

## 步驟 1:確認裝置與環境
IMU 已在[單元 0](00-usb-device-naming.md) 命名為 `/dev/usb_imu`。確認名稱存在,並執行環境檢查:

```bash
ls -l /dev/usb_imu          # 應顯示 /dev/usb_imu -> ttyUSB0(編號依電腦而異)
python3 imu.py              # 選 7 環境檢查
```

macOS 改為確認 `ls /dev/cu.usbserial*`。環境檢查全部通過再往下。

## 步驟 2:進入即時資料檢視
```bash
python3 imu.py
# 選 4 IMU 校正工具(自動使用 /dev/usb_imu)→ 選 1 即時資料檢視
```

畫面每秒更新數次,每次一行。以下是模組平放在桌上、靜止時的實際輸出:

```
roll=   -0.13 pitch=    0.23 yaw=  101.09 deg | accel=( -0.05, -0.03,  9.82) m/s^2 | gyro=(   0.00,   0.00,   0.00) deg/s | mag=(4746,-931,1858) LSB
```

一行分成四組,以 `|` 隔開。`Ctrl+C` 回到選單。

### 第一組:姿態角 roll、pitch、yaw

```
roll=   -0.13 pitch=    0.23 yaw=  101.09 deg
```

模組內部融合後的姿態,單位是度。三個角度的意義見單元 1 的「roll、pitch、yaw」。

| 欄位 | 範例值 | 意義 | 這個數值說明什麼 |
|---|---|---|---|
| `roll` | −0.13° | 繞 X 軸(前後方向)的傾斜 | 接近 0,模組左右沒有傾斜 |
| `pitch` | 0.23° | 繞 Y 軸(左右方向)的傾斜 | 接近 0,模組前後沒有傾斜 |
| `yaw` | 101.09° | 繞 Z 軸(上下方向)的朝向 | 模組目前的朝向。數值本身取決於模組擺放的方向與零點設定,沒有對錯;重點是靜止時應保持穩定 |

roll 與 pitch 沒有剛好等於 0,是因為桌面不會完全水平,加上加速度計有少量偏移。±0.5° 以內屬正常。

### 第二組:加速度 accel

```
accel=( -0.05, -0.03,  9.82) m/s^2
```

加速度計的讀數,依序為 X、Y、Z 三軸,單位 m/s²。

| 軸 | 範例值 | 這個數值說明什麼 |
|---|---|---|
| X | −0.05 | 接近 0,前後方向沒有受力 |
| Y | −0.03 | 接近 0,左右方向沒有受力 |
| Z | 9.82 | 約等於重力加速度 9.8,表示 Z 軸朝上、模組平放 |

靜止時讀到的不是 0 而是 9.8,因為加速度計量到的是桌面托住模組的力(單元 1)。
把模組立起來,9.8 會移到另一軸;三軸的合成大小(三軸平方和開根號)不論模組怎麼擺都應約為 9.8,此例為 9.82。

### 第三組:角速度 gyro

```
gyro=(   0.00,   0.00,   0.00) deg/s
```

陀螺儀的讀數,依序為繞 X、Y、Z 三軸的旋轉速度,單位是度/秒。

模組靜止,所以三軸都是 0。轉動模組時,對應的軸會出現數值,停下來後回到 0。
靜止時若某一軸固定顯示非零的數值,那就是陀螺儀的偏移 (bias),由校正處理。

### 第四組:磁力計 mag

```
mag=(4746,-931,1858) LSB
```

磁力計的讀數,依序為 X、Y、Z 三軸量到的磁場強度。

單位 LSB 是感測器的原始刻度,不是物理單位,所以數值大小本身不代表什麼,也不能拿來和別的模組或別的地點比較。要看的是兩件事:

| 觀察 | 正常情況 |
|---|---|
| 靜止時 | 三個數值穩定,只有約 ±20–30 的小幅抖動 |
| 轉動模組時 | 三個數值各自改變,但三軸的合成大小大致不變(此例約 5181) |

三個數值的比例反映地磁場相對於模組的方向,模組就是靠它算出 yaw。
數值在模組沒動的情況下跳動,表示附近有鐵件、磁鐵或電流干擾(單元 3)。

## 步驟 3:靜置觀察
把模組**平放在桌上,Z 軸(元件面)朝上,不要碰**。逐項對照:

| 觀察 | 物理預期 | 若不符合 |
|---|---|---|
| accel z | ≈ +9.8 m/s²;x、y 接近 0 | 差超過 0.5 → 桌面不平或加速度計需校正(實作 2) |
| accel 抖動 | 每次更新變動約 ±0.02 m/s² | 這是雜訊 (noise),不是 bias;bias 是平均值偏離 0 或 9.8 的部分 |
| gyro | 三軸 ≈ 0 deg/s | 有固定非零值 → 陀螺儀 bias |
| roll、pitch | 接近 0° | accel 的 x、y 偏離 0 越多,roll、pitch 偏離 0° 也越多 |
| yaw | 任意值,但應**穩定** | 若緩慢變化 → 磁力計受干擾或未校正 |
| mag 三軸 | 固定值,抖動約 ±20–30 LSB | 若跳動大 → 附近有物體在移動,例如手機 |

另一個檢查方法:accel 三軸的合成大小(三軸平方和開根號)應為 9.8 左右,而且不隨模組方向改變。
磁力計同理,三軸的合成大小在轉動時應維持不變(單元 3 會用到)。

## 步驟 4:動一動
每個動作列有預期的變化,操作後對照畫面:

1. **把模組立起來,X 軸朝上**。觀察 accel 三軸與 roll、pitch。預期:9.8 m/s² 移到 X 軸,pitch 約為 ±90°。
2. **沿桌面平移模組**(不旋轉)。觀察 accel、姿態角、gyro。
   預期:accel 短暫變化,gyro 與角度幾乎不動;融合濾波器對陀螺儀的權重高於加速度計的瞬時值。
3. **原地繞 Z 軸慢慢轉 90°**。觀察 yaw 變化量、accel、mag 三軸與合成大小。
   預期:yaw 變化約 90°,accel 不變,mag 的 x、y 改變而長度不變。
4. **快速轉一下再停住**。觀察 gyro 的峰值,以及停止後 yaw 是否持續變化。

動作 3 的 yaw 變化量若明顯偏離 90°(例如 75° 或 105°),是磁力計未校正的症狀,實作 2 處理。

## 常見問題

- **選單打不開序列埠**:同一時間只能有一個程式開序列埠。
  Windows 上若開著 WitMotion 上位機(repo 內 `IMU standard PC software` 資料夾),先關掉。
- **數值全是 0 或畫面不動**:鮑率不對(曾被改過)或線沒接好;環境檢查會列出序列埠但看不出鮑率。
- **WSL 裝置忽然消失**:在 `wsl_usb_auto` 選「查看所有規則」確認監聽仍在執行,必要時選「啟動監聽」。

## 本實作的結果

完成後應已確認:靜置時 accel 的 z 軸約為 9.8 m/s²、gyro 接近 0、mag 穩定;並得到校正前「水平轉 90°」的 yaw 變化量。
後者在實作 2 校正後會再量一次,用來比較校正前後的差異。
