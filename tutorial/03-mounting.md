# 3. 決定裝在哪

**三件事:朝向、位置、固定。**

## 朝向

- 板上的 **X 箭頭對準車頭**
- **元件面朝上**

這樣裝,ROS 的設定就不用另外轉換。

## 位置:離磁場來源遠一點

磁力計靠地球磁場判斷方向,地磁很弱,旁邊有鐵或磁鐵就會錯。

| 要遠離 | 沒關係 |
|---|---|
| 馬達、喇叭、磁鐵 | 鋁 |
| 鐵製支架、鋼螺絲 | 銅 |
| 電池、通電的電源線 | 塑膠、木頭 |
| 通電中的電器、變壓器 | |

- 至少離 10 cm,越遠越好
- 支架與螺絲用塑膠或鋁

干擾只會讓 **yaw** 出錯,roll、pitch 不受影響。

## 固定

- 鎖緊在車體上,不能晃
- 盡量靠近車子的旋轉中心

## 校正能補什麼

| 干擾來源 | 校正有用嗎 |
|---|---|
| 跟 IMU 一起動的鐵件(車架) | 有。裝好後在原位重新校正 |
| 環境裡的鐵件(鐵桌、鐵櫃) | 沒有。只能拉開距離 |
| 轉動中的馬達、變動的電流 | 沒有 |

## 親眼看一次干擾

開著第 2 頁的即時資料檢視,模組不動,拿鐵片從遠處慢慢靠近。
`mag` 和 yaw 會變,鐵片拿開後恢復。
