# 3. 決定裝在哪

**六軸只要顧兩件事:朝向、固定。** 改用九軸時,才要再加上「離磁場來源遠一點」。

## 朝向

- 板上的 **X 箭頭對準車頭**
- **元件面朝上**

這樣裝,ROS 的設定就不用另外轉換。

## 固定

- 鎖緊在車體上,不能晃
- 盡量靠近車子的旋轉中心
- 遠離馬達,減少振動

裝好後,在車上做加速度計校正(第 4 頁選項 `2`)。

---

## 九軸才需要:離磁場來源遠一點

本教材用六軸,這一節可以跳過。改用九軸(第 7 頁說明什麼時候需要)時才看。

磁力計靠地球磁場判斷方向,地磁很弱,旁邊有鐵或磁鐵就會錯。

| 要遠離 | 沒關係 |
|---|---|
| 馬達、喇叭、磁鐵 | 鋁 |
| 鐵製支架、鋼螺絲 | 銅 |
| 電池、通電的電源線 | 塑膠、木頭 |
| 通電中的電器、變壓器 | |

- 至少離 10 cm,越遠越好
- 支架與螺絲用塑膠或鋁

干擾只會讓 **yaw** 出錯,roll、pitch 不受影響。

### 校正能補什麼

| 干擾來源 | 校正有用嗎 |
|---|---|
| 跟 IMU 一起動的鐵件(車架) | 有。裝好後在原位重新校正 |
| 環境裡的鐵件(鐵桌、鐵櫃) | 沒有。只能拉開距離 |
| 轉動中的馬達、變動的電流 | 沒有 |

### 用工具判斷位置合不合適

九軸模式下選磁力計校正(`3` 或 `4`)時,工具會先自動檢查。

工具用 IMU 自己的讀數判斷:磁場穩不穩、附近有沒有鐵、馬達轉動時有沒有干擾、振動大不大、裝得正不正。
不合格會說明原因和怎麼改;不想在這裡校正就回答不要,不會送出任何指令。

### 親眼看一次干擾

開著第 2 頁的即時資料檢視,模組不動,拿鐵片從遠處慢慢靠近。
`mag` 會變,鐵片拿開後恢復。九軸時 yaw 也會跟著變。
