# 講師手冊

給授課者看的,學生不需要讀。

## 課前必做(最晚前一天)

1. **每台筆電下載好 Docker 映像**:`python3 imu.py` → `1`。映像由 GitHub 預先建置,不需在本機建置;下載約 2–3 GB,
   課堂上做會佔用大量上課時間。下載後跑 `7 環境檢查` 確認。
2. **WSL2 的前置安裝**:在 Windows 裝好 usbipd-win(`winget install usbipd`)並重開 WSL;建議同時在 `/etc/wsl.conf` 啟用 systemd,讓 udev 服務隨 WSL 啟動。
   序列埠權限不需另外設定:`usb_udev_namer` 建立的規則已開放讀寫權限。
3. **每顆模組先插一次**確認鮑率是 9600、即時資料檢視中四種資料都有數值。曾被上位機改過設定的模組,用校正工具 `11` 恢復原廠。
4. **每顆模組先做一次完整校正並驗證**,確認模組本身沒問題。課堂上再 `11` 恢復原廠,讓學生從未校正狀態開始,
   才看得到校正前後的差別。
5. 教室檢查:桌面是否鐵製(很多教室是鋼腳鐵框桌)。是的話磁力計校正要在木桌或塑膠椅上做,
   否則「轉一圈回原位」永遠不合格。先用自己的模組在教室試一次。
6. 準備每組:方盒子(厚書也行)、小鐵片、水平儀(手機 app)。

## 器材與分組

- 2–3 人一組,一組一顆模組一台筆電。超過 3 人會有人整堂沒碰到。
- 備用 USB 線 2 條、備用模組 1 顆。CP2102 的線材品質參差,接觸不良是最常見的硬體問題。
- 至少一台筆電是 Linux 原生,WSL 與 macOS 的 USB 轉接環節多,出問題時可以換機。

## 進度落後時的取捨

優先保住:實作 1 的靜置觀察、實作 2 的步驟 1–2、實作 3 的步驟 1、單元 5 的第 2–4 節(TF 與 EKF 設定)。

可省略:實作 1 的「快速轉」、實作 2 的步驟 6(軟體 hard-iron)、實作 3 的步驟 3、單元 5 第 5 節的細節。

## 各段常見卡關點

### 單元 0

- WSL2 的使用者要先在 Windows 裝好 usbipd-win 並重開 WSL,這一步放課前準備。
- `wsl_usb_auto` 新增規則時 Windows 會跳出系統管理員確認視窗,學生常沒注意到視窗在背景。
- WSL 預設可能沒有啟動 udev,`usb_udev_namer` 命名後名稱不出現;處理方式見單元 0 的常見問題。建議課前就讓 WSL 啟用 systemd。
- 全班統一命名為 `usb_imu`,不要讓學生自訂。
- macOS 的使用者略過本單元。

### 介紹 / 實作 1

- `Permission denied`:單元 0 的命名未完成;命名後裝置即開放讀寫權限。
- WSL 看不到 `/dev/ttyUSB0`:`wsl_usb_auto` 的規則未建立或監聽未啟動,或 Windows 端有程式佔住序列埠。
- macOS 看不到 `/dev/cu.usbserial*`:缺 CP210x 驅動。
- 序列埠被佔用:學生開了第二個終端機也進校正工具。一次只能一個。
- 數值全 0:線接觸不良,換線。

### 單元 1 常見誤解

- 「加速度計靜止時應該讀 0」:最常見,要正面處理。用「桌面托著它」的說法比「等效原理」好懂。
- 「陀螺儀直接量角度」:要強調量的是角速度,角度是積分來的,積分才有漂移。
- 「yaw 不準是陀螺儀不好」:多半是磁力計。單元 3 的干擾實驗後會自己想通。

### 實作 2

- **磁力計校正在鐵桌上做**:永遠校不好,見課前檢查第 5 點。
- 學生轉太快:進度條以磁力計覆蓋判斷,轉快沒用,慢慢轉每個方向都到才有用。
- 有一軸一直不滿:幾乎都是沒繞那一軸垂直的方向轉。工具有提示「X 不夠 → 繞 Y 或 Z」,請學生看畫面。
- 手機放口袋:喇叭磁鐵在 20 cm 內。校正時全組手機放到另一張桌子。
- 加速度計校正時桌子被人撞到:5 秒內的事,重做即可。
- 選項 9 的 `accel_bias` 超過 1 m/s²:模組沒放平,工具會警告。
- 按 `y` 之前沒看注意事項就按:工具會印完整注意事項,提醒學生看完再按。硬體校正是永久寫入。

### 單元 5

- 教室沒有實車時,本單元以講解為主;檢查指令(第 6 節)可在容器 shell 內對 `/imu/data` 操作。
- 第 4 節以 `urdf_odom_pkg` 為例,該套件的預設值針對 Isaac Sim 的模擬車。實體 CMP10A 搭配該套件尚未實際執行過,上課前請在實際的車上跑一次,並確認「接上實體 CMP10A 時要修改的地方」三項。
- 學生最常犯的錯是 TF 重複發佈(driver 的 `publish_tf` 與里程計節點的 TF 沒關),講第 2 節時用 `view_frames` 的輸出圖說明。
- 模組預設 10 Hz,若車輛需要更高頻率,課前先用上位機調好並更新 `baud`。

### 實作 3

- Foxglove 瀏覽器版連不上 `ws://localhost:8765`:瀏覽器阻擋混合內容,換桌面版。
- 3D 面板看不到東西:Display frame 沒設 `world`。
- driver 起來了但校正工具的序列埠被佔用:兩者不能同時,`6 停止容器` 後再進校正工具。
- WSL 下 RViz2 視窗不出來:本課用 Foxglove,不碰 RViz2,省得除錯 WSLg。
