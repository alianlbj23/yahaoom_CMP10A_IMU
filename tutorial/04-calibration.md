# 4. 校正

**校正 = 告訴 IMU 一個已知的狀態,讓它算出自己的誤差。**
所以每一項都有「要在哪裡做」的要求。

## 開始

```bash
python3 imu.py
```

選 `4 IMU 校正工具`。寫入前工具會問 `(y/N)`,看完說明再按 `y`。

## 校正前:先清空周圍

**磁力計校正時,周圍不能有電器與鐵製品。** 它們會產生或扭曲磁場,校正出來的結果就是錯的。

離模組至少 20 cm,能更遠更好:

| 類別 | 例子 |
|---|---|
| 通電中的電器 | 筆電、螢幕、延長線、變壓器、充電器、電源供應器 |
| 有電流的線 | 充電線、電源線、馬達線 |
| 有磁鐵的東西 | 手機、喇叭、耳機、馬達、磁吸支架 |
| 鐵製品 | 鐵桌、鐵櫃、螺絲起子、鑰匙、鋼尺 |

做法:

- 手機、手錶拿下來放遠
- 模組用**長一點的 USB 線**接筆電,把模組拉離筆電
- 不要在鐵桌上做;用木桌、塑膠椅,或拿在手上
- 車上的馬達、其他設備**先斷電**再校正

例外:車體本身的鐵件會跟著 IMU 一起動,校正時要留著,這樣才能一併補償。

加速度計(`2`)與陀螺儀(`9`)不受電器影響,但需要**完全靜止**:桌子不能被碰到,旁邊不要有振動的機器。

## 建議順序

`2` 加速度計 → 裝上車 → `3` 磁力計 → `6` 角度參考 → `9` 陀螺儀偏移 → `12` 驗證

對自走車最重要的是 **`9` 陀螺儀偏移**:車子靠它判斷轉了多少。

---

## 每個選項

### `1` 即時資料檢視

- **用途**:看目前的數值。不寫入任何東西
- **驗證**:不需要。各欄位的意思見[第 2 頁](02-read-data.md)

### `2` 加速度計水平校正

- **用途**:修正「有多斜」的誤差,讓平放時 roll、pitch 是 0
- **做法**:平放、元件面朝上、不要碰,等 5 秒
- **在哪**:水平桌面(用水平儀確認)。可以裝車前單獨做
- **驗證**:平放時 roll、pitch 在 ±0.5° 內;立起來變化約 90°

### `3` 磁力計校正(球面擬合)

- **用途**:修正「朝哪邊」的誤差,讓 yaw 準確
- **做法**:**整台車連同 IMU 一起**,繞 X、Y、Z 三個軸各慢慢轉幾圈,三條進度條都滿、出現 `[完成]` 後按 Enter。
  車上的鐵件要跟著一起轉,才會被算進去。車子搬不動就改用 `4`
- **在哪**:裝好的最終位置;周圍沒有電器與鐵製品(見上方「校正前:先清空周圍」)
- **驗證**:水平每轉 90°,yaw 變化約 90°(±3°);轉一圈回到原位,yaw 回到原值

進度條不滿時補哪個方向:

| 不滿的 | 繞這些軸轉 |
|---|---|
| X | Y 或 Z |
| Y | X 或 Z |
| Z | X 或 Y |

### `4` 磁力計校正(雙平面)

- **用途**:同 `3`,給車子太大、沒辦法三個軸都翻轉時用
- **做法**:車子在地上原地轉一圈,再把車立起來(側立或車頭朝上)轉一圈
- **在哪**:同 `3`
- **驗證**:同 `3`。效果比 `3` 差,能用 `3` 就用 `3`

**進度條有一軸一直不滿(例如 Z 停在 95%)**

這是正常的,不是轉錯。

- 原因:地磁是斜的(在台灣朝北、斜向下約 35°),不是水平的。只在水平面上轉的那一軸,最多只掃到八成左右
- 處理:直接按 Enter 結束,再用 `12` 驗證。合格就不用管
- 想讓它滿:把元件面朝各個斜角慢慢掃一遍
- 舊版工具的門檻較嚴,容易卡住。先在 `imu.py` 選 `1` 重新下載映像,更新到新版

### `5` Z 軸航向歸零

- **用途**:把現在的方向當成 yaw = 0
- **做法**:車頭對準要當作「正前方」的方向,確認,等 1 秒
- **驗證**:執行後 yaw 應接近 0
- **注意**:這顆模組的 yaw 以磁北為準,執行後 yaw 可能沒有變化。沒變不代表壞掉,自走車的設定也用不到 yaw 的零點

### `6` 設定角度參考

- **用途**:把現在的姿態當成 roll = 0、pitch = 0。用來修正 IMU 裝歪了幾度
- **做法**:IMU 裝上車後,車子停在水平地面,確認,等 1 秒
- **驗證**:執行後 roll、pitch 接近 0
- **注意**:只能修小角度。每次重新安裝都要重做

### `7` 高度歸零

- **用途**:把現在的高度當成 0 m
- **做法**:先用 `13` 開啟氣壓輸出,在要當作 0 的高度執行
- **驗證**:`12` 顯示的高度接近 0;抬高 1 m,高度增加約 1 m(會有數十公分的誤差)
- **注意**:氣壓隨天氣變,每次使用前重做

### `8` 讀取偏移暫存器

- **用途**:看模組裡存了哪些校正值。不寫入任何東西
- **會看到**:

| 名稱 | 是哪一項校正的結果 |
|---|---|
| `AXOFFSET` `AYOFFSET` `AZOFFSET` | 加速度計(`2`) |
| `GXOFFSET` `GYOFFSET` `GZOFFSET` | 陀螺儀 |
| `HXOFFSET` `HYOFFSET` `HZOFFSET` | 磁力計(`3`、`4`) |

- **怎麼用**:校正前後各讀一次。數值有變,表示有寫進模組;全部是 0,表示從沒校正過
- **注意**:數值有變只代表「有寫入」,不代表「校得好」。好不好要用 `12` 驗證

### `9` 軟體靜態偏移(陀螺儀、加速度計)

- **用途**:修正陀螺儀偏移。**自走車最需要這一項**

陀螺儀偏移:模組明明沒在轉,陀螺儀卻顯示它在轉。像沒歸零的體重計。

```
正常:  gyro=( 0.00, 0.00, 0.00) deg/s
有偏移:gyro=( 0.00, 0.00, 0.10) deg/s
```

角度是把「轉多快」一直累加出來的,所以偏移會越積越多:

| 經過時間 | 0.10 deg/s 的偏移累積成 |
|---|---|
| 1 分鐘 | 6° |
| 10 分鐘 | 60° |

校正就是靜止時量出這個固定值,之後每筆資料都扣掉它。

- **做法**:平放、元件面朝上、不要碰,等 5 秒
- **在哪**:水平面,而且模組已通電 5 分鐘以上
- **驗證**:靜止放 3 分鐘,yaw 幾乎不變
- **結果存在**:電腦的 `config/imu_calibration.yaml`

```yaml
gyro_bias: [x, y, z]     # 陀螺儀偏移,單位 rad/s
accel_bias: [x, y, z]    # 加速度計偏移,單位 m/s^2
```

`accel_bias` 任一個數字超過 1,表示模組沒放平,重做。

### `10` 軟體磁力計校正

- **用途**:補 `3` 之後剩下的磁力計誤差
- **做法**:同 `3`,三條進度條都滿會自動結束
- **在哪**:同 `3`
- **驗證**:同 `3`
- **結果存在**:`config/imu_calibration.yaml` 的 `mag_offset`

### `11` 恢復原廠設定

- **用途**:清掉模組裡所有校正,重新開始
- **做法**:確認兩次
- **驗證**:`8` 讀到的數值回到原廠值
- **注意**:之後要重做 `2`、`3`

### `12` 姿態檢視 / 校正驗證

- **用途**:確認上面各項校正有沒有效。不寫入任何東西
- **做法**:按 Enter 進入逐項驗證,工具一步一步帶著做,合格顯示綠色、不合格顯示紅色。見[第 5 頁](05-verification.md)

### `13` 氣壓高度輸出 開 / 關

- **用途**:讓模組開始輸出氣壓與高度(出廠預設是關的)
- **驗證**:開啟後 `12` 看得到高度

---

## 校正值存在哪裡

| 選項 | 存在 | 怎麼看 | 換電腦 |
|---|---|---|---|
| `2`–`7`、`13` | 模組裡 | 選 `8` | 還在 |
| `9`、`10` | 電腦的 `config/imu_calibration.yaml` | `cat config/imu_calibration.yaml` | 要帶著檔案,或重做 |

`9`、`10` 做完後,要重新啟動 driver(`imu.py` 選 `2`)才會套用。

## 延伸想法:讓陀螺儀偏移自動校正

> 這是一個想法,**本專案沒有實作**。

選項 `9` 要人去按,而且偏移會隨溫度改變。手錶、手機的做法是讓程式自己找機會校正:

1. **判斷靜止**:最近 2–3 秒,陀螺儀讀數幾乎不變,而且加速度合成大小接近 9.8。
   自走車還可以加一個條件:輪子速度是 0
2. **算偏移**:靜止期間陀螺儀的平均值,就是當下的偏移
3. **慢慢套用**:新值只佔一小部分(例如一成),避免一次誤判造成跳動

這樣車子每次停下來,偏移就更新一次,溫度造成的變化也跟著修掉。

限制:

- 只適用陀螺儀。磁力計靜止時沒有新資訊,無法這樣校正
- 只能修正送出去的角速度,改不到模組內部算的 roll、pitch、yaw
- 車子一直不停,就沒有機會更新

## 校正後畫面朝向沒變,是正常的

校正讓數值變**準**,不會讓它**歸零**。
yaw 的 0 度是磁北,模組朝哪裡擺,就顯示那個方位。
