# 4. 校正

**校正 = 告訴 IMU 一個已知的狀態,讓它算出自己的誤差。**
每一步都照官方軟體(WitMotion 使用說明 v23-0529 第 3.3 節)的做法,只是改在終端機顯示進度條與提示。

## 開始

```bash
python3 imu.py
```

選 `4 IMU 校正工具`。寫入前工具會問 `(y/N)`,看完說明再按 `y`。

**選單會跟著模式變**:工具一開始先讀模組現在是六軸還是九軸,只列出用得到的項目。

- 六軸:不顯示 `3`、`4`(磁力計校正)
- 九軸:不顯示 `5`(Z 軸歸零)
- 讀不到模式:全部列出
- 編號不變,教材寫的編號都對得上。用 `10` 切換模式後,選單跟著更新

**選單上的綠色**:某一項校正成功後,選單上那一行會變成綠色,並標上 `✓ 本次已完成`。

- 綠色只代表「這次開啟工具之後做過」。關掉重開,綠色會全部消失
- 沒有綠色不代表沒校正過,只是這次還沒做
- 取消、中途中斷、磁力計沒轉滿,都不會變綠
- 選 `11` 恢復原廠後,綠色會全部清掉

## 本教材的做法:六軸

室內自走車用六軸(原因見第 1 頁、第 7 頁)。六軸的 yaw 不用磁力計,所以只要校正兩樣,磁力計(`3`、`4`)完全不用管。

| 項目 | 做法 | 頻率 | 影響 |
|---|---|---|---|
| 陀螺儀偏移 | 上電後靜置約 5 秒不要動,模組會自動校正(狀態看 `9`) | 每次開機 | 直接影響 vyaw(轉向速度),最重要 |
| 加速度計水平校正 | `2`:IMU 裝在車上的最終位置,車子停在真正水平的地面 | 裝好後做一次 | 只影響 roll、pitch |

順序:

1. `10` 切換到六軸(做一次就好,設定存在模組裡)
2. 把 IMU 裝上車(第 3 頁)
3. `2` 加速度計:車子停在真正水平的地面。需要**完全靜止**:車子不能被碰到、馬達要停,旁邊不要有振動的機器
4. `5` Z 軸歸零:官方建議切換到六軸後做一次;之後每次上電,模組會自動把 Z 軸歸零

- `6` 角度參考:`2` 已經在車上做過,就不需要。官方也警告兩者一起用可能造成異常
- 什麼時候要重新校正,見[第 5 頁](05-recalibration.md)

## 改用九軸時

需要磁力計時(什麼時候需要,見第 7 頁),順序改成:
`10` 切換到九軸 → 裝上車 → `2` 加速度計 → `3` 或 `4` 磁力計(IMU 在車上時,連車一起轉)。

### 磁力計校正前:先清空周圍

**磁力計校正時,周圍不能有電器與鐵製品。** 它們會產生或扭曲磁場,校正出來的結果就是錯的。

官方:離電腦 50 cm 以上,拿在空中轉,不要直接在桌面上轉(桌下常有鐵樑)。

| 類別 | 例子 |
|---|---|
| 通電中的電器 | 筆電、螢幕、喇叭、延長線、變壓器、充電器 |
| 有電流的線 | 充電線、電源線、馬達線 |
| 有磁鐵的東西 | 手機、耳機、馬達、磁吸支架 |
| 鐵製品 | 鐵桌、桌下鐵架、地板鋼筋、螺絲起子、鑰匙 |

做法:

- 手機、手錶拿下來放遠
- 模組用**長一點的 USB 線**接筆電,把模組拉離筆電
- 校正轉動時,車上的馬達要**停住**(下面的自動檢查會請你短暫開一下馬達,測完就停)

例外:車體本身的鐵件會跟著 IMU 一起動,校正時要留著,這樣才能一併補償。

### 工具會自動檢查

選 `3`、`4`(磁力計校正)時,工具會先檢查,約 1 分鐘:

| 檢查 | 你要做的 | 抓什麼 |
|---|---|---|
| 1 磁場穩定 | 放著不動 5 秒 | 附近有東西在變動(馬達、電流、有人拿手機經過) |
| 2 附近有無鐵件 | 等畫面顯示「準備好了」,**不要轉動**,把 IMU 或整台車平移約 30 cm 再停住 | 鐵桌、鐵櫃、筆電、地板鋼筋 |
| 3 安裝方向 | (裝上車時)自動判斷 | 元件面有沒有朝上、歪幾度 |
| 4 馬達干擾 | (裝上車時)架高車子,馬達停 → 再讓馬達轉 | IMU 離馬達或電源線太近 |
| 5 振動 | 同上 | IMU 沒鎖緊、太靠近馬達 |

- 選 `3` 會問 IMU 是否已裝在車上;選 `4` 不問,直接檢查安裝位置(雙平面本來就是給翻不動、已裝好的車用的)
- 全程自動判斷,不用按 Enter。平移時轉動了,這次自動作廢,停住後自動重來
- 馬達轉了卻 10 秒都沒偵測到,代表影響很小,這時才能按 Enter 開始量(太早按會被拒絕,避免量到馬達還沒轉的資料)
- 全部合格:顯示綠色,繼續校正
- 有項目略過或資料異常:顯示「檢查未完成」,不能據此判斷環境合適
- 有不合格:說明原因和改善方式,問你要不要繼續。回答要,**會再問一次**。兩次都回答要,才照你的意思校正

## 每個選項

### `1` 即時資料檢視

- **用途**:看目前的數值。不寫入任何東西。各欄位的意思見[第 2 頁](02-read-data.md)

### `2` 加速度計水平校正

- **用途**:修正「有多斜」的誤差,讓車子停在平地時 roll、pitch 是 0
- **做法(官方)**:水平、靜止放置 2 秒
- **在哪**:IMU **裝在車上的最終位置**,而且車子停在**真正水平的地面**(用水平儀確認)。兩個條件要同時成立
- **做完會顯示**:目前的三軸加速度與角度。官方:應約為 0、0、1 g,角度約 0°
- **注意**:IMU 裝歪的角度會一起被當成偏移寫進模組,所以重新安裝後要重做 `2`

### `3` 磁力計校正(橢球,九軸)

- **用途**:修正「朝哪邊」的誤差,讓 yaw 準確
- **做法(官方)**:
  1. 先用手機找出南北方向
  2. 開始後,讓 XY、XZ、YZ 三個平面各轉 1–3 圈
  3. 三條進度條都滿、出現 `[完成]` 後按 Enter,寫入參數
- **在哪**:離電腦 50 cm,拿在空中轉。IMU 已裝在車上時,**連車一起轉**,車上的鐵件才會被算進去。車子搬不動就改用 `4`

進度條不滿時怎麼補:

| 不滿的平面 | 繞這個軸轉 |
|---|---|
| XY | Z(平放原地轉) |
| XZ | Y |
| YZ | X |

### `4` 磁力計校正(雙平面,九軸)

- **用途**:同 `3`,給車子太大、沒辦法拿起來轉時用
- **做法(官方)**:
  1. 先放水平(傾斜不可超過 15°;工具會先量,太斜不會開始)
  2. 第 1 段:保持水平,慢慢轉一圈
  3. 第 2 段:垂直立起來(側立或車頭朝上),慢慢轉一圈
  4. 出現 `[完成]` 後按 Enter
- 第 1 段轉滿,畫面自動換到第 2 段

**沒轉滿就按 Enter**:工具會說還缺哪個平面,再明確確認才儲存(預設不儲存),手動儲存不會標綠。完全沒資料或讀取失敗不會儲存;未儲存後請重新上電。

進度條只看轉的方向夠不夠,不代表校正品質。

### `5` Z 軸角度歸零(六軸)

- **用途**:把現在的方向當成 yaw = 0
- **限制(官方)**:**只在六軸演算法有效**。九軸的 yaw 是以磁北為準的絕對角度,不能歸零
- **做法**:靜止放置,確認,等 1 秒。工具會先讀演算法設定,九軸時直接拒絕並提示用 `10` 切換
- 六軸模式下,模組每次上電 Z 軸也會自動歸零

### `6` 設定角度參考

- **用途**:把現在的姿態當成 roll = 0、pitch = 0。用來修正 IMU 裝歪了幾度
- **官方警告**:和加速度計校正(`2`)同時使用,可能造成加速度、角度異常。工具會先顯示這段警告再問一次
- **做法**:IMU 裝上車後,車子停在水平地面,確認,等 1 秒

### `7` 高度歸零

- **用途**:把現在的高度當成 0 m
- **做法**:先用 `12` 開啟氣壓輸出,在要當作 0 的高度執行
- **注意**:氣壓隨天氣變,每次使用前重做

### `8` 讀取偏移暫存器

- **用途**:看模組裡存了哪些校正值。不寫入任何東西

| 名稱 | 是哪一項校正的結果 |
|---|---|
| `AXOFFSET` `AYOFFSET` `AZOFFSET` | 加速度計(`2`) |
| `GXOFFSET` `GYOFFSET` `GZOFFSET` | 陀螺儀 |
| `HXOFFSET` `HYOFFSET` `HZOFFSET` | 磁力計(`3`、`4`) |

- 數值有變代表「有寫進模組」;全部是 0,表示從沒校正過

### `9` 陀螺儀自動校正 狀態(唯讀)

陀螺儀偏移:模組明明沒在轉,陀螺儀卻顯示它在轉。像沒歸零的體重計。

| 經過時間 | 0.10 °/s 的偏移累積成 |
|---|---|
| 1 分鐘 | 6° |
| 10 分鐘 | 60° |

- **官方**:模組預設會自動校正陀螺儀。角速度變化小於門檻時當作靜止,輸出 0。所以陀螺儀**不用手動校正**
- **這個選項**:只讀出門檻(`0x61`)與判定時間(`0x63`),不寫入
- **何時要關**:官方說只有「等速旋轉」的用途要關(等速轉會被當成靜止)。自走車不用關
- 這顆模組的開關指令還沒確認,本工具不提供開關;需要時用官方 Windows 軟體
- **對自走車最重要**:車子靠陀螺儀判斷轉了多少

### `10` 演算法 六軸 / 九軸

| | 九軸 | 六軸 |
|---|---|---|
| yaw 由誰決定 | 磁力計,以磁北為準 | 陀螺儀累加,上電時為 0 |
| 漂移 | 不會 | 會慢慢漂 |
| 怕磁場干擾 | 怕 | 不怕 |

- **本教材**:切換到六軸
- **做法**:工具先讀出目前設定,確認後寫入並讀回確認
- **官方**:切換後要重做 `2`;六軸再做 `5`,九軸再做 `3` 或 `4`

### `11` 恢復原廠設定

- **用途**:清掉模組裡所有校正,重新開始
- **做法**:確認兩次
- 之後照「建議順序」重做

### `12` 氣壓高度輸出 開 / 關

- **用途**:讓模組開始輸出氣壓與高度(出廠預設是關的)

## 校正值存在哪裡

全部存在**模組裡**(`2`–`7`、`10`、`12`),換電腦還在。選 `8` 看得到偏移暫存器。

舊版工具做過的軟體偏移存在 `config/imu_calibration.yaml`,driver 仍會套用:
重做 `2` 會把 `accel_bias` 歸零,重做 `3` / `4` 會把 `mag_offset` 歸零,`11` 全部歸零。

## 延伸想法:在電腦端自動校正陀螺儀

> 這是一個想法,**本專案沒有實作**。模組本身已有自動校正(`9`)。

手錶、手機的做法是讓程式自己找機會校正:

1. **判斷靜止**:最近 2–3 秒,陀螺儀讀數幾乎不變,而且加速度合成大小接近 9.8。
   自走車還可以加一個條件:輪子速度是 0
2. **算偏移**:靜止期間陀螺儀的平均值,就是當下的偏移
3. **慢慢套用**:新值只佔一小部分(例如一成),避免一次誤判造成跳動

限制:

- 只適用陀螺儀。磁力計靜止時沒有新資訊,無法這樣校正
- 只能修正送出去的角速度,改不到模組內部算的 roll、pitch、yaw
- 車子一直不停,就沒有機會更新

## 校正後畫面朝向沒變,是正常的

校正讓數值變**準**,不會讓它**歸零**。
六軸時 yaw 的 0 度是開機時的方向;九軸時是磁北,模組朝哪裡擺,就顯示那個方位。
