# 2. 讀出資料

**目標:看到 IMU 的數值,知道每個數字的意思。** 這一頁不會改動任何設定。

## 開始

```bash
python3 imu.py
```

選 `4 IMU 校正工具` → 選 `1 即時資料檢視`。`Ctrl+C` 離開。

## 畫面上的一行

```
roll= -0.13 pitch= 0.23 yaw= 101.09 deg | accel=( -0.05, -0.03, 9.82) m/s^2 | gyro=( 0.00, 0.00, 0.00) deg/s | mag=(4746,-931,1858) LSB
```

| 欄位 | 意思 | 平放靜止時應該 |
|---|---|---|
| `roll`、`pitch` | 有多斜(度) | 接近 0 |
| `yaw` | 朝哪邊(度),0 是磁北 | 任意值,但**穩定不動** |
| `accel` | X、Y、Z 三軸受力 | 前兩個接近 0,第三個約 9.8(重力) |
| `gyro` | 繞 X、Y、Z 轉多快 | 三個都是 0 |
| `mag` | X、Y、Z 三軸磁場 | 穩定,小幅抖動 |

`mag` 的單位是原始刻度,數字大小本身沒有意義,只看它穩不穩。

## 動手試

| 動作 | 會看到 |
|---|---|
| 把模組立起來 | 9.8 跑到另一軸,roll 或 pitch 變成約 90 |
| 水平轉 90° | yaw 變化約 90,`gyro` 第三個數字短暫跳動 |
| 拿鐵片靠近 | `mag` 與 yaw 變動,模組明明沒動 |

水平轉 90° 時 yaw 若只變 75 或變了 105,表示磁力計需要校正(第 4 頁)。

## 出問題時

| 現象 | 處理 |
|---|---|
| 打不開序列埠 | 同時只能一個程式用;關掉其他視窗 |
| 畫面沒有數值 | 換一條 USB 線 |
