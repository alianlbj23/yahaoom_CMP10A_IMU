# 5. 確認校正成功

工具顯示「完成」不算數。**要拿已知的東西去比。**

## 開始

```bash
python3 imu.py
```

選 `4` → 選 `12` → 按 `Enter` 開始逐項驗證。

工具會一步一步帶著做:**照畫面擺好,按 Enter,它自己量、自己判定。**

- 綠色 `[合格]`:通過
- 紅色 `[不合格]`:沒過
- 黃色 `[略過]`:沒做

每一步都可以按 `s` 略過、`q` 結束。

畫面會**原地更新**:每做完一步就清掉舊內容,只留下目前的結果與下一步要做的事。

## 四個步驟

| 步驟 | 畫面要你做的事 | 合格 |
|---|---|---|
| 1 水平 | 放在水平面,按 Enter | roll、pitch 在 ±0.5° 內 |
| 2 每轉 90° | 靠著盒子的邊擺好,按 Enter;之後往同一個方向轉 90° 再按 Enter,共四次 | 每次約 90°(±3°) |
| 3 轉一圈回原位 | 不用再做,工具直接用步驟 2 的頭尾來判定 | 回到 0(±3°) |
| 4 高度 | 放在固定高度按 Enter,抬高 1 m 再按 Enter | 約 +1 m(±0.5 m) |

步驟 4 要先用選項 `13` 開啟氣壓輸出,沒開會自動略過。

## 畫面長這樣

```
步驟 1/4 水平:把 IMU 放在水平面(用水平儀確認),然後按 Enter(s 略過 / q 結束):
[合格] 1. 水平:roll +0.10°  pitch -0.20°(標準 ±0.5°)
步驟 2/4 每轉 90°:IMU 靠著方形盒子的邊,擺好起始方向,然後按 Enter(s 略過 / q 結束):
  第 1/4 次:往同一個方向轉 90°,然後按 Enter(s 略過 / q 結束):
  [合格] 第 1 次 Δyaw +90.50°
  ...
== 驗證結果 ==
[合格] 1. 水平:roll +0.10°  pitch -0.20°(標準 ±0.5°)
[合格] 2. 每轉 90°:4 次(標準 90° ±3°)
[合格] 3. 轉一圈回原位:Δyaw +1.00°(標準 0° ±3°)
[略過] 4. 高度:未收到高度資料,先用選項 13 開啟氣壓輸出
```

步驟 2 最重要:磁力計沒校好時,四次會是 80、100、85、95 這種樣子。

另外可以手動確認陀螺儀:模組放著不動 3 分鐘,yaw 幾乎不變。
選 `12` 後按 `f` 進入自由檢視,按 Enter 設參考點,就能看變化量。自由檢視只有一行,會一直在同一行更新。

## 不合格時先檢查

- 桌面真的水平嗎
- 磁力計校正時三個軸都轉滿了嗎
- 校正當時,周圍 20 cm 內有沒有電器、通電的線、手機、鐵製品

條件沒變,重做結果也一樣。

## 用圖看磁力計(選做)

```bash
python3 imu.py
```

選 `2`,開 [Foxglove](https://app.foxglove.dev) 連 `ws://localhost:8765`。

想在 3D 面板看模組轉動:先在 `imu.py` 選 `8`,把「發佈 world → frame 的 TF」打開(預設是關的)。

Plot 面板:X 軸填 `/imu/mag.magnetic_field.x`,Y 軸填 `/imu/mag.magnetic_field.y`,把模組水平轉一圈。

| 畫出來的形狀 | 意思 |
|---|---|
| 圓,圓心在原點附近 | 校正良好 |
| 圓心偏掉 | 還沒校好 |
| 橢圓,或某處凹進去 | 旁邊有鐵件 |

## 裝上車以後

車上的鐵件和馬達不同,**在最終位置重做磁力計校正,再驗證一次**。
