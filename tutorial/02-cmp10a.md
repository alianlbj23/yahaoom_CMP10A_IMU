# 單元 2:CMP10A 模組的特性

## 這顆模組的特性

Yahboom CMP10A 是以 WitMotion 方案為基礎的 10 軸模組:三軸加速度計、三軸陀螺儀、三軸磁力計、氣壓計,
加上一顆做感測器融合的 MCU,透過 UART 輸出。板上接 CP2102 USB-UART 晶片,插上電腦就是一個序列埠。

本 repo 在 2026-11-09 實機驗證過的事實(見 [docs/SPEC.md](../docs/SPEC.md)):

| 項目 | 值 |
|---|---|
| USB 介面 | CP2102,VID `10c4` / PID `ea60`;Linux 顯示為 `/dev/ttyUSB*`,macOS 為 `/dev/cu.usbserial*` |
| 預設鮑率 | 9600 baud(可改到 115200,但本課維持預設) |
| 預設輸出 | 加速度、角速度、角度、磁力計四種資料,約 10 Hz |
| 加速度量程 | ±16 g |
| 角速度量程 | ±2000 °/s |
| 角度輸出 | roll、pitch ±180°,yaw ±180°(晶片內融合後的 Euler 角) |
| 磁力計輸出 | 原始 LSB,不是 μT |
| 氣壓計 | 出廠預設**不輸出**,要用校正工具選項 13 開啟 |

對本課最重要的三個特性:

1. **融合在模組內完成**。收到的 roll/pitch/yaw 已經是融合後的值,不需要自己處理;
   濾波器的參數也無法調整。
2. **校正結果寫在模組的 flash**。硬體校正做一次就永久有效,換電腦也在;
   做壞了也一樣永久,所以有「恢復原廠設定」。
3. **磁力計輸出原始值**。沒有換算成 μT,單位是 LSB(least significant bit,ADC 最小刻度)。
   做 yaw 用的是方向,不是絕對強度,所以原始值就夠了;但要注意不同環境下的總強度不能直接比。

## 本單元重點

- 10 軸模組,內建融合用的 MCU,以 USB 序列埠連接電腦
- 預設 9600 baud、約 10 Hz
- 硬體校正的結果存在模組內,跟著模組走
- 磁力計輸出原始值;氣壓計預設關閉,需以校正工具選項 13 開啟
