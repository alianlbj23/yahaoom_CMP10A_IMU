# 5. 什麼時候要重新校正

校正值存在模組裡,不會自己消失。但下面這些情況,原本的校正就不適用了。

本教材用六軸:表中標「九軸」的項目都可以跳過。

| 情況 | 重做什麼 | 為什麼 |
|---|---|---|
| 每次開機 | 靜置約 5 秒不要動 | 模組會自動校正陀螺儀偏移(第 4 頁選項 `9`) |
| 第一次裝上車、重新安裝 IMU | `2`;九軸再做 `3` 或 `4` | 裝的角度變了;車上的鐵件和馬達也跟桌上不同 |
| 換使用場地 | 九軸:`3` 或 `4` | 周圍的鐵件、地板鋼筋不同 |
| 車上加了馬達、電池或鐵件 | 九軸:`3` 或 `4` | 車上的磁場變了 |
| 摔過、撞過 | `2`;九軸再做 `3` 或 `4` | 模組或安裝角度可能被撞歪 |
| 切換六軸 / 九軸(`10`) | `2`;六軸再做 `5`,九軸再做 `3` 或 `4` | 官方要求 |
| 要用高度時 | `7` | 氣壓隨天氣變,每次使用前重做 |
