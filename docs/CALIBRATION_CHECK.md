# 校正檢測規格(選項 12)

本文件說明「怎麼判定一顆 CMP10A 校正得好」:用什麼方法、依據哪些標準、合格門檻多少、門檻怎麼來的。
程式實作在 `wit_ros2_imu/wit_ros2_imu/calibration_check.py`,門檻都是該檔開頭的常數。

## 原則

**每一項都拿 IMU 以外的已知參考,比對感測器的原始讀數。**

不使用模組自己融合算出的 roll / pitch / yaw 來判定,否則等於模組自己說自己對。
檢測時會先套用 `config/imu_calibration.yaml` 的軟體校正,與 ROS driver 實際輸出的數值一致。

| 參考 | 性質 |
|---|---|
| 重力 | 大小固定(約 9.79–9.81 m/s²),方向朝下 |
| 靜止 | 角速度為 0 |
| 桌上的參考線 | 轉一圈對回同一條線 = 實際轉了 360° |
| 世界地磁模型(WMM) | 查得到當地地磁場的傾角 |

## 依據的標準

| 標準 | 名稱 | 本檢測引用的內容 |
|---|---|---|
| [IEEE Std 2700-2017](https://standards.ieee.org/ieee/2700/6770/) | IEEE Standard for Sensor Performance Parameter Definitions | 加速度計、陀螺儀、磁力計等感測器的效能參數定義(偏移、靈敏度等) |
| [IEEE Std 1293-2018](https://doi.org/10.1109/IEEESTD.2019.8653544) | IEEE Standard Specification Format Guide and Test Procedure for Linear Single-Axis, Nongyroscopic Accelerometers | 多點翻轉(multipoint tumble)測試。本檢測的六面測試是其簡化形式,只用每軸 ±1 g 兩點 |
| [IEEE Std 952-2020](https://standards.ieee.org/standard/952-2020.html) | IEEE Standard for Specifying and Testing Single-Axis Interferometric Fiber Optic Gyros | 陀螺儀偏移與刻度因子的測試方式。原為光纖陀螺制定,MEMS 陀螺儀普遍沿用 |
| [World Magnetic Model 2025](https://www.ncei.noaa.gov/products/world-magnetic-model) | 美國 NOAA NCEI 與英國地質調查局(BGS)共同發佈,有效期 2025–2029 | 當地磁傾角(Inclination,I) |

IEEE 標準全文受著作權保護、需付費取得,本 repo 不收錄全文,只列編號與連結,可在 IEEE Xplore 或學校圖書館查閱。

**標準定義的是「怎麼量」,不定義「多少算合格」。** 合格門檻要由使用者依規格書或應用需求決定。

## 為什麼門檻由本專案訂定

Yahboom 沒有公開 CMP10A 的精度規格(偏移穩定度、雜訊、航向誤差等),官方資料只有量程。
因此門檻無法引用原廠數字,改為依「這個誤差會造成多大的角度誤差」推算,推算過程列在下方。
有更嚴格的需求時,修改 `calibration_check.py` 開頭的常數即可。

## 五項檢測

### 1. 加速度計 六面測試

| 項目 | 內容 |
|---|---|
| 做法 | 用方形盒子讓 X、Y、Z 軸各朝上、朝下,共 6 面,每面靜止量 5 秒取平均 |
| 參考 | 重力。不論哪一面朝上,合成大小都應是 1 g;同一軸朝上與朝下的讀數應互為正負 |
| 合格 | ① 每一面的合成大小與 9.80665 m/s² 差 0.1 m/s² 內 ② 每一軸的偏移(朝上與朝下讀數的平均)在 ±0.1 m/s² 內 |
| 門檻理由 | 0.1 m/s² 的誤差造成約 0.6° 的傾角誤差(arcsin(0.1 / 9.8))。台灣的重力約 9.79 m/s²,與標準值差約 0.02,在容許範圍內 |
| 抓得到 | 偏移(① 與 ②)、刻度誤差(①) |

### 2. 陀螺儀 靜止測試

| 項目 | 內容 |
|---|---|
| 做法 | IMU 靜止 5 分鐘,取三軸平均。期間被移動會自動重新開始 |
| 參考 | 靜止時角速度為 0 |
| 合格 | 三軸平均都在 ±0.02°/s 內 |
| 門檻理由 | 0.02°/s 累加一分鐘約 1.2°。單筆讀數的解析度是 0.061°/s(±2000°/s 量程 ÷ 32768),5 分鐘約 3000 筆的平均可以分辨到比單筆更小 |
| 抓得到 | 陀螺儀偏移(選項 9 的校正結果) |
| 不包含 | Allan variance 的偏移穩定度分析,需要數小時的資料 |

### 3. 陀螺儀 轉一圈測試

| 項目 | 內容 |
|---|---|
| 做法 | IMU 平放對齊桌上的參考線,慢慢轉一整圈(10 秒以上)對回同一條線,把陀螺儀 Z 軸讀數對時間累加 |
| 參考 | 參考線:實際轉了 360° |
| 合格 | 累加結果 360° ± 3° |
| 門檻理由 | 3° / 360° 約 0.8% 的刻度誤差,並包含對線時約 1° 的人為誤差 |
| 抓得到 | 陀螺儀刻度因子誤差 |
| 注意 | 必須看參考線對齊,不看螢幕數字;所以這一項不會自動結束,要按 Enter。CMP10A 沒有可校正陀螺儀刻度的指令,不合格時只能記錄 |

### 4. 磁力計 合成大小

| 項目 | 內容 |
|---|---|
| 做法 | 往各個方向慢慢轉,記錄磁力計讀數,直到三軸都涵蓋完整 |
| 參考 | 地磁場在一個地點的大小固定,不隨 IMU 方向改變 |
| 合格 | 95% 的讀數,合成大小落在平均值 ±5% 內 |
| 門檻理由 | 殘留偏移為場強的 r 倍時,合成大小會變動約 ±r,航向誤差最大約 arcsin(r);5% 對應約 2.9°。只看 95% 的讀數,是為了不讓偶發的干擾(例如有人拿手機經過)決定結果 |
| 抓得到 | hard-iron 偏移、soft-iron 變形 |

### 5. 磁力計 磁傾角

| 項目 | 內容 |
|---|---|
| 做法 | 使用第 4 項中轉得夠慢時的資料,計算磁場與重力的夾角 |
| 參考 | WMM 給出的當地磁傾角。查詢:<https://www.ngdc.noaa.gov/geomag/calculators/magcalc.shtml>(台灣約 30–37°,依地點不同) |
| 合格 | 量到的平均磁傾角與 WMM 差 3° 內 |
| 門檻理由 | 與第 4 項一致的角度量級 |
| 抓得到 | 磁力計與加速度計的軸向不一致、刻度誤差、soft-iron 變形 |
| 抓不到 | hard-iron 偏移:對所有方向取平均時,固定偏移的影響會互相抵消。這由第 4 項負責,所以兩項都要做 |
| 注意 | 室內的鋼筋、鐵製家具會改變當地磁場,可能使量到的值偏離 WMM;應在遠離大型金屬的地方做 |

## 判定

**五項全部合格,才判定這顆 IMU 校正良好。** 選單第 12 項會在本次執行中五項都合格後顯示綠色。

任何一項略過,都不算全部合格。

## 不在本檢測範圍

| 項目 | 原因 |
|---|---|
| 航向的絕對精度(指北指得準不準) | 需要已知方位的參考物,例如依地圖量出方位的建築邊線 |
| 陀螺儀的偏移穩定度、角度隨機漂移 | 需要數小時的靜止資料做 Allan variance 分析 |
| 溫度造成的偏移變化 | 需要控溫設備 |
| 氣壓高度 | 與姿態校正無關 |

## 尚未以實機確認的假設

- 磁傾角的計算假設 CMP10A 的磁力計三軸與加速度計三軸方向一致。本專案只用模擬資料測試過;若實機量到的磁傾角與 WMM 正負相反或差距固定,可能是軸向定義不同,需要修正計算方式
- 門檻是依上方的推算訂定,尚未以多顆模組的實測資料統計驗證
